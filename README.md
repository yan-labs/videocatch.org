## What it does

vidown reads a public post the way a signed-out visitor would and hands back every file it holds: the best MP4 encodes, the full-resolution photos of a carousel, or both when a post mixes them. Multi-item posts get a "Download all as zip" button that packs the files in your browser.

Nothing is uploaded to vidown, nothing is stored, and there is no account. Your browser fetches the media from the platform's CDN; for a few CDNs that refuse browser downloads, vidown streams the file through without keeping a copy.

## Principles

- **Original files, not re-encodes.** You get the encode the platform serves its own player, at every quality it offers.
- **No storage.** Files never sit on a vidown server. Cached metadata expires within an hour.
- **No account, no tracking beyond aggregate counts.** See the [privacy policy](https://vidown.org/privacy).
- **Rights holders are heard.** Takedown requests go to hello@vidown.org and are answered; see the [copyright and takedown policy](https://vidown.org/dmca).
